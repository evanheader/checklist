# Daily Checklist

A mobile-friendly dark-themed personal checklist web app.

## Features

- Add tasks
- Remove tasks
- Mark tasks as completed
- Daily reset at 12:00am PST
- Android-friendly layout with a dark grayscale and blue accent theme
- App icon and web manifest included

## Project structure

- `index.html` — main HTML entry point
- `css/styles.css` — dark theme and responsive styling
- `js/script.js` — checklist logic and local storage
- `assets/catmeme.png` — app icon asset
- `manifest.webmanifest` — progressive web app manifest

## Usage

Open `index.html` in a browser or host with a static server.
